Pip Value Calculator

What one pip is worth on your forex position. Pick a lot size, set the pip size, and (if your account currency differs from the pair's quote currency) add the conversion rate.

Estimate only, not financial advice.

How it's calculated

Pip value (quote currency) = P × U
Pip value (account currency) = P × U × X
  • P — pip size: 0.0001 for most pairs, 0.01 for JPY pairs
  • U — position size in units (1 standard lot = 100,000; mini = 10,000; micro = 1,000)
  • X — quote→account exchange rate; use 1 when the quote currency is your account currency

Worked example

You trade 1 standard lot (100,000 units) of USD/JPY in a USD account, with USD/JPY at 150.

In yen: 0.01 × 100,000 = ¥1,000 per pip.

Quote→account rate X = 1 ÷ 150 ≈ 0.006667, so pip value = 1,000 × 0.006667 ≈ $6.67 per pip. A 30-pip stop therefore risks about $200.

Frequently Asked Questions

What is a pip?

A pip is the standard smallest price move in forex — 0.0001 for most pairs, or 0.01 for JPY pairs. Pip value is how much one pip is worth on your position: pip size × position size (in units), expressed in the quote currency.

How do I convert pip value to my account currency?

If the pair's quote currency equals your account currency (e.g. EUR/USD for a USD account), pip value is already in your currency. Otherwise multiply by the quote→account exchange rate — enter it in the optional field.

How much is 1 pip worth on a standard lot?

On a standard lot (100,000 units) one pip is worth 10 units of the quote currency — $10 on EUR/USD, GBP/USD and other USD-quoted pairs. A mini lot (10,000 units) is $1 per pip and a micro lot (1,000 units) is $0.10 per pip.

How much is a pip worth on USD/JPY?

On USD/JPY a pip is 0.01, so one standard lot moves 1,000 yen per pip — about $6.67 when USD/JPY is at 150. The dollar value changes with the exchange rate because the pip is denominated in yen.

How do I use pip value to size a position?

Divide the amount you want to risk by your stop distance in pips to get the pip value you can afford, then choose the lot size that produces it. Risking $200 with a 20-pip stop on EUR/USD allows $10 per pip, which is one standard lot.
